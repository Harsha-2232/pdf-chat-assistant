# PDF Chat Assistant

AI-powered PDF Chat Assistant using RAG, FastAPI, FAISS, and React.

## Features
- Upload PDF files
- Ask questions from PDFs
- AI-powered responses
- FastAPI backend
- React frontend
- Vector search using FAISS

## Tech Stack
- Python
- FastAPI
- React + Vite
- FAISS
- Gemini/OpenAI API

## Installation

### Backend

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
